# Gate: Type Safety and Dependencies

## 目的

TypeScript の型境界を維持し、不要な依存追加や `any` による曖昧な実装を防ぐ。

## 判定条件

- [ ] 新規または変更した TypeScript で `any` を追加していない。
- [ ] 外部入力または境界データを扱う場合、型または既存データ構造に基づく narrow を行っている。
- [ ] 既存依存で実現できる処理のために新規依存を追加していない。
- [ ] 新規依存を追加する場合、必要性と既存依存では不十分な理由が説明されている。

## 不合格条件

- [ ] 型エラー回避のために `as any`、`@ts-ignore`、理由のない `@ts-expect-error` を追加している。
- [ ] ライブラリ API を確認せず、存在が不明なオプションや戻り値に依存している。
- [ ] lockfile に不要または説明不能な依存差分が入っている。

## 判定

YES / NO
