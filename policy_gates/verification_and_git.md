# Gate: Verification and Git

## 目的

変更後に必要な確認を実行し、既存の未コミット変更と今回の作業差分を混ぜない。

## 判定条件

- [ ] 作業完了時に `git status` を確認している。
- [ ] 今回変更したファイルと、作業開始前から存在する未コミット変更を区別している。
- [ ] 実行可能な lint、型チェック、build、画面確認を行い、結果を報告している。
- [ ] 差分が 300 行以上の場合、commit の要否と対象差分を確認している。

- [ ] 引継ぎ版はサイトをルートからビルドでき、Excel原本は `reference/`、公開承認済みの配布物は `public/` にある。ビルド結果・ローカル設定・非公開資料は追跡対象から外れている。

## 不合格条件

- [ ] ユーザーの既存未コミット変更を revert、上書き、commit に混入している。
- [ ] 実行できなかった確認を理由なしに省略している。
- [ ] 失敗した確認を成功扱いで報告している。

## 判定

YES / NO
