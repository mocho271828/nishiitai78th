# Gate: Project State and Compatibility

## 目的

導入済みプロジェクトとして、既存利用者が使っている URL、UI 操作、認証境界を意図せず壊さない。

## 判定条件

- [ ] 既存の公開 URL または `basePath` を変更していない。
- [ ] 既存画面にある主要なタブ、ボタン、リンクの意味を変更していない。
- [ ] 既存の認証ガードを削除、迂回、緩和していない。
- [ ] Board添付を公開URLへ置く場合、対象文書について管理者の明示承認があり、データと画面表示の両方で公開状態を明示している。
- [ ] JSON や静的データの既存キーを、利用箇所の移行なしに削除・変更していない。

- [ ] 公開サンプルの選手・役員・連絡先・記事・配布資料は架空であり、編集原本を含めて実資料を収録していない。公開対象の履歴と接続設定に本番情報がない。

## 不合格条件

- [ ] 既存 URL が事前合意なしに 404、未認証迂回、別画面遷移へ変わる。
- [ ] 既存ユーザー操作が事前合意なしに消える、または別の意味になる。
- [ ] 認証が必要な画面から gate や guard が外れている。
- [ ] 公開URLのBoard添付を、関係者限定または認証必須のファイルであるかのように表示している。

## 判定

YES / NO
